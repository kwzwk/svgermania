# Logo

Eine Datei `logo.svg` in diesem Ordner erscheint automatisch oben links im Kopfbereich. Ohne Datei bleibt der Platz leer.

Nur ein Logo verwenden, für das ihr die Rechte habt (z. B. das Vereinslogo von SV Germania). Das DFB-Logo ist eine geschützte Marke und darf nur mit Erlaubnis des DFB verwendet werden.
